# Start Here

This project is prepared for a local Codex workflow.

## First Session

1. Open this repository in Codex.
2. Read `AGENTS.md`.
3. If this is a new project, run `$gsd-new-project`.
4. If this is an existing codebase, run `$gsd-map-codebase`.

## What Is Local Here

- local `.codex/` skills and agents
- local GSD workflow support files
- local repo instructions in `AGENTS.md`

## Suggested Working Pattern

1. Define scope and requirements with GSD.
2. Break work into phases and plans.
3. Implement with `tdd-workflow` and `coding-standards`.
4. Finish with `verification-loop` and `security-review`.
5. Add Axon later only if the project needs graph-aware code navigation.
6. Use Shannon only as a final security pass for a runnable web app.
